# keyboard-types 0.7.0 attribution

The upstream README attributes generated key and code definitions to W3C working
drafts. This version does not identify the dated draft revisions or supply
separate W3C license text; the attribution below preserves what it provides.

## Generated definitions

Reproduced verbatim from [README.md](https://github.com/pyfisch/keyboard-types/blob/61a081f1e78a881a369abc22c3a0e37049bd655e/README.md#L19-L26):

```text
The file `src/key.rs` and `src/code.rs` are derived from the two 
W3C working drafts

* [UI Events KeyboardEvent key Values](https://w3c.github.io/uievents-key/) and
* [UI Events KeyboardEvent code Values](https://w3c.github.io/uievents-code/)

in the most recent version. A Python 3 script (requires `requests` library)
downloads the files and updates the tables.
```
