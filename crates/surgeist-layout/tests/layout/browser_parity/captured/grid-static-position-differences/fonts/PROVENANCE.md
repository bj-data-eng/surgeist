# Prepared-text Ahem fixture

`Ahem.ttf` is copied unchanged from the existing
[Text fixture](../../../../../surgeist-text/tests/fixtures/fonts/ahem/PROVENANCE.md),
which preserves its original Render fixture provenance. The upstream source is
[W3C Ahem](https://www.w3.org/Style/CSS/Test/Fonts/Ahem/).

SHA-256: `f0a92cd0cc45735591c9b5b1fa8aecd5194e8dc518895ca22af94a46c23550dc`.

The browser producer and independent Rust reader use these same bytes and face
index zero. This TTF is distinct from the WOFF2 embedded in the older base CSS.
It is a test resource, with no font transformation or new acquisition.
