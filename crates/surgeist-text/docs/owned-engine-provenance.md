## Current ownership and phases

[AnalyzedSource](../src/analyzed.rs) retains one immutable original Source, resolved source span winners, original atom facts and analysis identity. It can supply logical accessibility without fonts. Font preparation retains that same analysis and the actual selected strong FontData, canonical coordinates and synthesis. The private standalone chooser selects genuine mixed-item endpoints, calls the selected-line finalizer, applies L1 and the canonical supplied-line L2, then places those exact rows. Layout, borrowed views, interaction and placed accessibility read one committed result. Composed public preparation/selection and Layout float feedback remain separate work.

Every original atom obtains its bidi class from ICU `get32` using the original code point. Scalar shaping flags, script and grapheme-break facts retain the packed provider data; isolated UTF-16 units obtain their raw properties directly. A private segmentation-only U+00A6 projection uses the pinned ICU 2.2 constructor/property equivalence; glyph production separately projects an isolated unit to U+FFFD. Original source, bidi and font/source association do not read the segmentation representative. Host UTF-8 projection refuses ill-formed original units atomically. Source-local ProcessedSource remains its existing owner; the standalone Preserve path does not reinterpret it as an adopted document/line formatter.

Every actual shaping result checks the maintained provider’s returned completion status before extraction, metric derivation or row publication. Resource/plan lookup caches retain their actual resources; successful Layout cache lookup also compares captured inputs and required analysis identity. Logical geometry and spacing use finite f64; actual provider font sizes and glyph offsets/advances remain canonical f32. Finalized pens and outer origins are retained separately.

## Preserved and selected metric behavior

Line and strikeout metrics reuse the existing [same-instance owner](../src/font/metrics.rs), including its qualified variable-font selection and accumulation. Concrete synthesis follows the tracked contract’s executable x-shear and positive actual-size/36 translated-outline displacement; it changes outline ink without a spacing adjustment. Render owns execution and representation admission.

For a genuinely absent optional underline metric, this cutover preserves the prior literal positive units-per-em/18 top offset and thickness. That narrow existing fallback is not a newly selected CSS rule and is distinct from the contract’s scaled strikeout fallback. Ordinary shaping preserves the existing permissive optional underline accessor behavior. It does not introduce blanket strict admission of unrelated font tables.

The original [Ahem font and provenance](../tests/fixtures/fonts/ahem/PROVENANCE.md) remain unchanged. Repository-authored [shaping fixture tables](../src/test_fonts/shaping.rs) rebuild valid table directories over that resource to exercise literal ligature, mark-anchor and Arabic-form facts through the actual registered-font providers. No new font download or font-generation tool is required.
