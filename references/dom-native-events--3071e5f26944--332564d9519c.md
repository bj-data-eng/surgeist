4.  Initialize <var>event</var>’s <code><a id="ref&#45;for&#45;dom&#45;event&#45;istrusted⑤"></a>[isTrusted](#dom-event-istrusted)</code> attribute to true&#46;

5.  Return <var>event</var>&#46;

<strong>Note&#58;</strong>

<a id="ref&#45;for&#45;concept&#45;event&#45;create"></a>[Create an event](#concept-event-create) is meant to be used by other specifications which need to separately <a id="ref&#45;for&#45;concept&#45;event&#45;create①"></a>[create](#concept-event-create) and <a id="ref&#45;for&#45;concept&#45;event&#45;dispatch①⑧"></a>[dispatch](#concept-event-dispatch) events&#44; instead of simply <a id="ref&#45;for&#45;concept&#45;event&#45;fire"></a>[firing](#concept-event-fire) them&#46; It ensures the event’s attributes are initialized to the correct defaults&#46;

The <a id="inner&#45;event&#45;creation&#45;steps"></a><strong>inner event creation steps</strong>&#44; given an <var>eventInterface</var>&#44; <var>realm</var>&#44; <var>time</var>&#44; and <var>dictionary</var>&#44; are as follows&#58;

1.  Let <var>event</var> be the result of creating a new object using <var>eventInterface</var>&#46; If <var>realm</var> is non&#45;null&#44; then use that realm&#59; otherwise&#44; use the default behavior defined in Web IDL&#46;

    As of the time of this writing Web IDL does not yet define any default behavior&#59; see [whatwg&#47;webidl&#35;135](https://github.com/whatwg/webidl/issues/135)&#46;

2.  Set <var>event</var>’s <a id="ref&#45;for&#45;initialized&#45;flag①"></a>[initialized flag](#initialized-flag)&#46;

3.  Initialize <var>event</var>’s <code><a id="ref&#45;for&#45;dom&#45;event&#45;timestamp②"></a>[timeStamp](#dom-event-timestamp)</code> attribute to the <a id="ref&#45;for&#45;dfn&#45;relative&#45;high&#45;resolution&#45;coarse&#45;time"></a>[relative high resolution coarse time](https://w3c.github.io/hr-time/#dfn-relative-high-resolution-coarse-time) given <var>time</var> and <var>event</var>’s <a id="ref&#45;for&#45;concept&#45;relevant&#45;global"></a>[relevant global object](https://html.spec.whatwg.org/multipage/webappapis.html#concept-relevant-global)&#46;

4.  <a id="ref&#45;for&#45;map&#45;iterate"></a>[For each](https://infra.spec.whatwg.org/#map-iterate) <var>member</var> → <var>value</var> of <var>dictionary</var>&#58; if <var>event</var> has an attribute whose <a id="ref&#45;for&#45;dfn&#45;identifier"></a>[identifier](https://webidl.spec.whatwg.org/#dfn-identifier) is <var>member</var>&#44; then initialize that attribute to <var>value</var>&#46;

5.  Run the <a id="ref&#45;for&#45;concept&#45;event&#45;constructor&#45;ext"></a>[event constructing steps](#concept-event-constructor-ext) with <var>event</var> and <var>dictionary</var>&#46;

6.  Return <var>event</var>&#46;

An <code><a id="ref&#45;for&#45;eventtarget⑨"></a>[EventTarget](#eventtarget)</code> object represents a target to which an <a id="ref&#45;for&#45;concept&#45;event③⑦"></a>[event](#concept-event) can be <a id="ref&#45;for&#45;concept&#45;event&#45;dispatch①⑨"></a>[dispatched](#concept-event-dispatch) when something has occurred&#46;

Each <code><a id="ref&#45;for&#45;eventtarget①⓪"></a>[EventTarget](#eventtarget)</code> object has an associated <a id="eventtarget&#45;event&#45;listener&#45;list"></a><strong>event listener list</strong> &#40;a <a id="ref&#45;for&#45;list④"></a>[list](https://infra.spec.whatwg.org/#list) of zero or more <a id="ref&#45;for&#45;concept&#45;event&#45;listener①①"></a>[event listeners](#concept-event-listener)&#41;&#46; It is initially the empty list&#46;

An <a id="concept&#45;event&#45;listener"></a><strong>event listener</strong> can be used to observe a specific <a id="ref&#45;for&#45;concept&#45;event③⑧"></a>[event](#concept-event) and consists of&#58;

- <a id="event&#45;listener&#45;type"></a><strong>type</strong> &#40;a string&#41;
- <a id="event&#45;listener&#45;callback"></a><strong>callback</strong> &#40;null or an <code><a id="ref&#45;for&#45;callbackdef&#45;eventlistener②"></a>[EventListener](#callbackdef-eventlistener)</code> object&#41;
- <a id="event&#45;listener&#45;capture"></a><strong>capture</strong> &#40;a boolean&#44; initially false&#41;
- <a id="event&#45;listener&#45;passive"></a><strong>passive</strong> &#40;null or a boolean&#44; initially null&#41;
- <a id="event&#45;listener&#45;once"></a><strong>once</strong> &#40;a boolean&#44; initially false&#41;
- <a id="event&#45;listener&#45;signal"></a><strong>signal</strong> &#40;null or an <code><a id="ref&#45;for&#45;abortsignal②"></a>[AbortSignal](https://dom.spec.whatwg.org/#abortsignal)</code> object&#41;
- <a id="event&#45;listener&#45;removed"></a><strong>removed</strong> &#40;a boolean for bookkeeping purposes&#44; initially false&#41;

<strong>Note&#58;</strong>

Although <a id="ref&#45;for&#45;event&#45;listener&#45;callback②"></a>[callback](#event-listener-callback) is an <code><a id="ref&#45;for&#45;callbackdef&#45;eventlistener③"></a>[EventListener](#callbackdef-eventlistener)</code> object&#44; an <a id="ref&#45;for&#45;concept&#45;event&#45;listener①②"></a>[event listener](#concept-event-listener) is a broader concept as can be seen above&#46;

Each <code><a id="ref&#45;for&#45;eventtarget①①"></a>[EventTarget](#eventtarget)</code> object also has an associated <a id="get&#45;the&#45;parent"></a><strong>get the parent</strong> algorithm&#44; which takes an <a id="ref&#45;for&#45;concept&#45;event③⑨"></a>[event](#concept-event) <var>event</var>&#44; and returns an <code><a id="ref&#45;for&#45;eventtarget①②"></a>[EventTarget](#eventtarget)</code> object&#46; Unless specified otherwise it returns null&#46;

<strong>Note&#58;</strong>

<a id="ref&#45;for&#45;concept&#45;node③"></a>[Nodes](https://dom.spec.whatwg.org/#concept-node)&#44; <a id="ref&#45;for&#45;concept&#45;shadow&#45;root①"></a>[shadow roots](#concept-shadow-root)&#44; and <a id="ref&#45;for&#45;concept&#45;document①"></a>[documents](https://dom.spec.whatwg.org/#concept-document) override the <a id="ref&#45;for&#45;get&#45;the&#45;parent"></a>[get the parent](#get-the-parent) algorithm&#46;

Each <code><a id="ref&#45;for&#45;eventtarget①③"></a>[EventTarget](#eventtarget)</code> object can have an associated <a id="eventtarget&#45;activation&#45;behavior"></a><strong>activation behavior</strong> algorithm&#46; The <a id="ref&#45;for&#45;eventtarget&#45;activation&#45;behavior"></a>[activation behavior](#eventtarget-activation-behavior) algorithm is passed an <a id="ref&#45;for&#45;concept&#45;event④⓪"></a>[event](#concept-event)&#44; as indicated in the <a id="ref&#45;for&#45;concept&#45;event&#45;dispatch②⓪"></a>[dispatch](#concept-event-dispatch) algorithm&#46;

<strong>Note&#58;</strong>

This exists because user agents perform certain actions for certain <code><a id="ref&#45;for&#45;eventtarget①④"></a>[EventTarget](#eventtarget)</code> objects&#44; e&#46;g&#46;&#44; the <code><a id="ref&#45;for&#45;the&#45;area&#45;element"></a>[area](https://html.spec.whatwg.org/multipage/image-maps.html#the-area-element)</code> element&#44; in response to synthetic <code><a id="ref&#45;for&#45;dom&#45;mouseevent"></a>[MouseEvent](https://w3c.github.io/pointerevents/#dom-mouseevent)</code> <a id="ref&#45;for&#45;concept&#45;event④①"></a>[events](#concept-event) whose <code><a id="ref&#45;for&#45;dom&#45;event&#45;type⑦"></a>[type](#dom-event-type)</code> attribute is <code>click</code>&#46; Web compatibility prevented it from being removed and it is now the enshrined way of defining an activation of something&#46; [&#91;HTML&#93;](https://dom.spec.whatwg.org/#biblio-html)

Each <code><a id="ref&#45;for&#45;eventtarget①⑤"></a>[EventTarget](#eventtarget)</code> object that has <a id="ref&#45;for&#45;eventtarget&#45;activation&#45;behavior①"></a>[activation behavior](#eventtarget-activation-behavior)&#44; can additionally have both &#40;not either&#41; a <a id="eventtarget&#45;legacy&#45;pre&#45;activation&#45;behavior"></a><strong>legacy&#45;pre&#45;activation behavior</strong> algorithm and a <a id="eventtarget&#45;legacy&#45;canceled&#45;activation&#45;behavior"></a><strong>legacy&#45;canceled&#45;activation behavior</strong> algorithm&#46;

<strong>Note&#58;</strong>

These algorithms only exist for checkbox and radio <code><a id="ref&#45;for&#45;the&#45;input&#45;element"></a>[input](https://html.spec.whatwg.org/multipage/input.html#the-input-element)</code> elements and are not to be used for anything else&#46; [&#91;HTML&#93;](https://dom.spec.whatwg.org/#biblio-html)

<strong><code><var>target</var> &#46; <a id="ref&#45;for&#45;dom&#45;eventtarget&#45;addeventlistener③"></a>[addEventListener](#dom-eventtarget-addeventlistener)&#40;<var>type</var>&#44; <var>callback</var> &#91;&#44; <var>options</var>&#93;&#41;</code></strong>

Appends an <a id="ref&#45;for&#45;concept&#45;event&#45;listener①③"></a>[event listener](#concept-event-listener) for <a id="ref&#45;for&#45;concept&#45;event④③"></a>[events](#concept-event) whose <code><a id="ref&#45;for&#45;dom&#45;event&#45;type⑧"></a>[type](#dom-event-type)</code> attribute value is <var>type</var>&#46; The <var>callback</var> argument sets the <a id="ref&#45;for&#45;event&#45;listener&#45;callback③"></a>[callback](#event-listener-callback) that will be invoked when the <a id="ref&#45;for&#45;concept&#45;event④④"></a>[event](#concept-event) is <a id="ref&#45;for&#45;concept&#45;event&#45;dispatch②②"></a>[dispatched](#concept-event-dispatch)&#46;

The <var>options</var> argument sets listener&#45;specific options&#46; For compatibility this can be a boolean&#44; in which case the method behaves exactly as if the value was specified as <var>options</var>’s <code><a id="ref&#45;for&#45;dom&#45;eventlisteneroptions&#45;capture"></a>[capture](#dom-eventlisteneroptions-capture)</code>&#46;

<strong><code><var>target</var> &#46; <a id="ref&#45;for&#45;dom&#45;eventtarget&#45;removeeventlistener②"></a>[removeEventListener](#dom-eventtarget-removeeventlistener)&#40;<var>type</var>&#44; <var>callback</var> &#91;&#44; <var>options</var>&#93;&#41;</code></strong>

<strong><code><var>target</var> &#46; <a id="ref&#45;for&#45;dom&#45;eventtarget&#45;dispatchevent③"></a>[dispatchEvent](#dom-eventtarget-dispatchevent)&#40;<var>event</var>&#41;</code></strong>

### <a id="observing&#45;event&#45;listeners"></a>2&#46;8&#46; Observing event listeners[](#observing-event-listeners)

In general&#44; developers do not expect the presence of an <a id="ref&#45;for&#45;concept&#45;event&#45;listener②②"></a>[event listener](#concept-event-listener) to be observable&#46; The impact of an <a id="ref&#45;for&#45;concept&#45;event&#45;listener②③"></a>[event listener](#concept-event-listener) is determined by its <a id="ref&#45;for&#45;event&#45;listener&#45;callback①⑤"></a>[callback](#event-listener-callback)&#46; That is&#44; a developer adding a no&#45;op <a id="ref&#45;for&#45;concept&#45;event&#45;listener②④"></a>[event listener](#concept-event-listener) would not expect it to have any side effects&#46;

Unfortunately&#44; some event APIs have been designed such that implementing them efficiently requires observing <a id="ref&#45;for&#45;concept&#45;event&#45;listener②⑤"></a>[event listeners](#concept-event-listener)&#46; This can make the presence of listeners observable in that even empty listeners can have a dramatic performance impact on the behavior of the application&#46; For example&#44; touch and wheel events which can be used to block asynchronous scrolling&#46; In some cases this problem can be mitigated by specifying the event to be <code><a id="ref&#45;for&#45;dom&#45;event&#45;cancelable⑦"></a>[cancelable](#dom-event-cancelable)</code> only when there is at least one non&#45;<code><a id="ref&#45;for&#45;dom&#45;addeventlisteneroptions&#45;passive④"></a>[passive](#dom-addeventlisteneroptions-passive)</code> listener&#46; For example&#44; non&#45;<code><a id="ref&#45;for&#45;dom&#45;addeventlisteneroptions&#45;passive⑤"></a>[passive](#dom-addeventlisteneroptions-passive)</code> <code><a id="ref&#45;for&#45;idl&#45;def&#45;touchevent①"></a>[TouchEvent](https://w3c.github.io/touch-events/#idl-def-touchevent)</code> listeners must block scrolling&#44; but if all listeners are <code><a id="ref&#45;for&#45;dom&#45;addeventlisteneroptions&#45;passive⑥"></a>[passive](#dom-addeventlisteneroptions-passive)</code> then scrolling can be allowed to start <a id="ref&#45;for&#45;in&#45;parallel"></a>[in parallel](https://html.spec.whatwg.org/multipage/infrastructure.html#in-parallel) by making the <code><a id="ref&#45;for&#45;idl&#45;def&#45;touchevent②"></a>[TouchEvent](https://w3c.github.io/touch-events/#idl-def-touchevent)</code> uncancelable &#40;so that calls to <code><a id="ref&#45;for&#45;dom&#45;event&#45;preventdefault⑧"></a>[preventDefault&#40;&#41;](#dom-event-preventdefault)</code> are ignored&#41;&#46; So code dispatching an event is able to observe the absence of non&#45;<code><a id="ref&#45;for&#45;dom&#45;addeventlisteneroptions&#45;passive⑦"></a>[passive](#dom-addeventlisteneroptions-passive)</code> listeners&#44; and use that to clear the <code><a id="ref&#45;for&#45;dom&#45;event&#45;cancelable⑧"></a>[cancelable](#dom-event-cancelable)</code> property of the event being dispatched&#46;

Ideally&#44; any new event APIs are defined such that they do not need this property&#46; &#40;Use [whatwg&#47;dom](https://github.com/whatwg/dom/issues) for discussion&#46;&#41;

In <a id="concept&#45;shadow&#45;including&#45;tree&#45;order"></a><strong>shadow&#45;including tree order</strong> is <a id="ref&#45;for&#45;shadow&#45;including&#45;preorder&#45;depth&#45;first&#45;traversal"></a>[shadow&#45;including preorder&#44; depth&#45;first traversal](#shadow-including-preorder-depth-first-traversal) of a <a id="ref&#45;for&#45;concept&#45;node&#45;tree②②"></a>[node tree](https://dom.spec.whatwg.org/#concept-node-tree)&#46; <a id="shadow&#45;including&#45;preorder&#45;depth&#45;first&#45;traversal"></a><strong>Shadow&#45;including preorder&#44; depth&#45;first traversal</strong> of a <a id="ref&#45;for&#45;concept&#45;node&#45;tree②③"></a>[node tree](https://dom.spec.whatwg.org/#concept-node-tree) <var>tree</var> is preorder&#44; depth&#45;first traversal of <var>tree</var>&#44; with for each <a id="ref&#45;for&#45;element&#45;shadow&#45;host④"></a>[shadow host](https://dom.spec.whatwg.org/#element-shadow-host) encountered in <var>tree</var>&#44; <a id="ref&#45;for&#45;shadow&#45;including&#45;preorder&#45;depth&#45;first&#45;traversal①"></a>[shadow&#45;including preorder&#44; depth&#45;first traversal](#shadow-including-preorder-depth-first-traversal) of that <a id="ref&#45;for&#45;concept&#45;element⑥⑨"></a>[element](https://dom.spec.whatwg.org/#concept-element)’s <a id="ref&#45;for&#45;concept&#45;element&#45;shadow&#45;root①③"></a>[shadow root](https://dom.spec.whatwg.org/#concept-element-shadow-root)’s <a id="ref&#45;for&#45;concept&#45;node&#45;tree②④"></a>[node tree](https://dom.spec.whatwg.org/#concept-node-tree) just after it is encountered&#46;

The <a id="concept&#45;shadow&#45;including&#45;root"></a><strong>shadow&#45;including root</strong> of an object is its <a id="ref&#45;for&#45;concept&#45;tree&#45;root③⓪"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root)’s <a id="ref&#45;for&#45;concept&#45;documentfragment&#45;host⑨"></a>[host](https://dom.spec.whatwg.org/#concept-documentfragment-host)’s <a id="ref&#45;for&#45;concept&#45;shadow&#45;including&#45;root⑤"></a>[shadow&#45;including root](#concept-shadow-including-root)&#44; if the object’s <a id="ref&#45;for&#45;concept&#45;tree&#45;root③①"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root) is a <a id="ref&#45;for&#45;concept&#45;shadow&#45;root④①"></a>[shadow root](#concept-shadow-root)&#59; otherwise its <a id="ref&#45;for&#45;concept&#45;tree&#45;root③②"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root)&#46;

An object <var>A</var> is a <a id="concept&#45;shadow&#45;including&#45;descendant"></a><strong>shadow&#45;including descendant</strong> of an object <var>B</var>&#44; if <var>A</var> is a <a id="ref&#45;for&#45;concept&#45;tree&#45;descendant③⓪"></a>[descendant](https://dom.spec.whatwg.org/#concept-tree-descendant) of <var>B</var>&#44; or <var>A</var>’s <a id="ref&#45;for&#45;concept&#45;tree&#45;root③③"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root) is a <a id="ref&#45;for&#45;concept&#45;shadow&#45;root④②"></a>[shadow root](#concept-shadow-root) and <var>A</var>’s <a id="ref&#45;for&#45;concept&#45;tree&#45;root③④"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root)’s <a id="ref&#45;for&#45;concept&#45;documentfragment&#45;host①⓪"></a>[host](https://dom.spec.whatwg.org/#concept-documentfragment-host) is a <a id="ref&#45;for&#45;concept&#45;shadow&#45;including&#45;inclusive&#45;descendant④"></a>[shadow&#45;including inclusive descendant](#concept-shadow-including-inclusive-descendant) of <var>B</var>&#46;

A <a id="concept&#45;shadow&#45;including&#45;inclusive&#45;descendant"></a><strong>shadow&#45;including inclusive descendant</strong> is an object or one of its <a id="ref&#45;for&#45;concept&#45;shadow&#45;including&#45;descendant①"></a>[shadow&#45;including descendants](#concept-shadow-including-descendant)&#46;

An object <var>A</var> is a <a id="concept&#45;shadow&#45;including&#45;ancestor"></a><strong>shadow&#45;including ancestor</strong> of an object <var>B</var>&#44; if and only if <var>B</var> is a <a id="ref&#45;for&#45;concept&#45;shadow&#45;including&#45;descendant②"></a>[shadow&#45;including descendant](#concept-shadow-including-descendant) of <var>A</var>&#46;

A <a id="concept&#45;shadow&#45;including&#45;inclusive&#45;ancestor"></a><strong>shadow&#45;including inclusive ancestor</strong> is an object or one of its <a id="ref&#45;for&#45;concept&#45;shadow&#45;including&#45;ancestor"></a>[shadow&#45;including ancestors](#concept-shadow-including-ancestor)&#46;

A <a id="ref&#45;for&#45;concept&#45;node①⑥②"></a>[node](https://dom.spec.whatwg.org/#concept-node) <var>A</var> is <a id="concept&#45;closed&#45;shadow&#45;hidden"></a><strong>closed&#45;shadow&#45;hidden</strong> from a <a id="ref&#45;for&#45;concept&#45;node①⑥③"></a>[node](https://dom.spec.whatwg.org/#concept-node) <var>B</var> if all of the following conditions are true&#58;

- <var>A</var>’s <a id="ref&#45;for&#45;concept&#45;tree&#45;root③⑤"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root) is a <a id="ref&#45;for&#45;concept&#45;shadow&#45;root④③"></a>[shadow root](#concept-shadow-root)&#46;

- <var>A</var>’s <a id="ref&#45;for&#45;concept&#45;tree&#45;root③⑥"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root) is not a <a id="ref&#45;for&#45;concept&#45;shadow&#45;including&#45;inclusive&#45;ancestor①"></a>[shadow&#45;including inclusive ancestor](#concept-shadow-including-inclusive-ancestor) of <var>B</var>&#46;

- <var>A</var>’s <a id="ref&#45;for&#45;concept&#45;tree&#45;root③⑦"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root) is a <a id="ref&#45;for&#45;concept&#45;shadow&#45;root④④"></a>[shadow root](#concept-shadow-root) whose <a id="ref&#45;for&#45;shadowroot&#45;mode⑥"></a>[mode](#shadowroot-mode) is &#34;<code>closed</code>&#34; or <var>A</var>’s <a id="ref&#45;for&#45;concept&#45;tree&#45;root③⑧"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root)’s <a id="ref&#45;for&#45;concept&#45;documentfragment&#45;host①①"></a>[host](https://dom.spec.whatwg.org/#concept-documentfragment-host) is <a id="ref&#45;for&#45;concept&#45;closed&#45;shadow&#45;hidden"></a>[closed&#45;shadow&#45;hidden](#concept-closed-shadow-hidden) from <var>B</var>&#46;

To <a id="retarget"></a><strong>retarget</strong> an object <var>A</var> against an object <var>B</var>&#44; repeat these steps until they return an object&#58;

1.  If one of the following is true

    - <var>A</var> is not a <a id="ref&#45;for&#45;concept&#45;node①⑥④"></a>[node](https://dom.spec.whatwg.org/#concept-node)
    - <var>A</var>’s <a id="ref&#45;for&#45;concept&#45;tree&#45;root③⑨"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root) is not a <a id="ref&#45;for&#45;concept&#45;shadow&#45;root④⑤"></a>[shadow root](#concept-shadow-root)
    - <var>B</var> is a <a id="ref&#45;for&#45;concept&#45;node①⑥⑤"></a>[node](https://dom.spec.whatwg.org/#concept-node) and <var>A</var>’s <a id="ref&#45;for&#45;concept&#45;tree&#45;root④⓪"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root) is a <a id="ref&#45;for&#45;concept&#45;shadow&#45;including&#45;inclusive&#45;ancestor②"></a>[shadow&#45;including inclusive ancestor](#concept-shadow-including-inclusive-ancestor) of <var>B</var>

    then return <var>A</var>&#46;

2.  Set <var>A</var> to <var>A</var>’s <a id="ref&#45;for&#45;concept&#45;tree&#45;root④①"></a>[root](https://dom.spec.whatwg.org/#concept-tree-root)’s <a id="ref&#45;for&#45;concept&#45;documentfragment&#45;host①②"></a>[host](https://dom.spec.whatwg.org/#concept-documentfragment-host)&#46;
