Each requested verified string is determined from the intended Element's current node-document global at the point verification is reached. The callback can change the tree or the Attr's owner. Capture the lexical operands and authentic global before execution, then use current owner and lookup facts for the post-verification steps. Reached policy effects and original abrupt completion retain their own outcomes. The CSP checks sample the captured Global at each reached step. Violation reporting queues delivery as specified by CSP3.

## Attribute-specific source decisions

An absent default policy produces no conversion. Continue to the policy mismatch decision, including report-only disposition. The selected draft defines the default policy as nullable, while its default-policy algorithm leaves the absent case implicit. The pinned WebKit implementation explicitly handles it, and the no-default-policy and report-only fixtures cover the observable decision. [Pinned WebKit default-policy path](https://github.com/WebKit/WebKit/blob/73aa6c89e2cb77c46184a81aec944e4ab99d114d/Source/WebCore/dom/TrustedType.cpp#L125-L186)

For sink classification, recognize the exact names of event handler content attributes in the supported HTML, SVG and MathML namespaces when the attribute namespace is null. Use the HTML event-handler index, the media content name `onwaitingforkey`, and the SVG animation content names `onbegin`, `onend` and `onrepeat`. The pinned [encrypted-media IDL](https://github.com/web-platform-tests/wpt/blob/69f2bba61ce7e9469ccbce53de4644a89f6b7dff/interfaces/encrypted-media.idl) and [SVG animation IDL](https://github.com/web-platform-tests/wpt/blob/69f2bba61ce7e9469ccbce53de4644a89f6b7dff/interfaces/svg-animations.idl) identify those supplemental names. Names can qualify on a receiver where the handler itself has narrower applicability. The pinned WebKit attribute classifier and the tentative event-handler fixture corroborate that distinction. [Pinned WebKit attribute classifier](https://github.com/WebKit/WebKit/blob/73aa6c89e2cb77c46184a81aec944e4ab99d114d/Source/WebCore/dom/TrustedType.cpp#L232-L271), [pinned event-handler fixture](https://github.com/web-platform-tests/wpt/blob/69f2bba61ce7e9469ccbce53de4644a89f6b7dff/trusted-types/set-event-handlers-content-attributes.tentative.html#L28-L101)
