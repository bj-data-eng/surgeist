# BCP 47: HTML language-tag source boundary

This metadata-only reference identifies the external language-tag specification cited by the selected HTML language clause. HTML owns selecting and preserving an element's effective language; a selected string is not a registry-validation result. No RFC prose, table, syntax production or ABNF is reproduced here.

- Title: Tags for Identifying Languages.
- Identifier: RFC 5646, BCP 47; September 2009; obsoletes RFC 4646.
- Editors: A. Phillips (Lab126) and M. Davis (Google).
- Definitive source: [RFC 5646](https://www.rfc-editor.org/rfc/rfc5646.txt).
- Selected research sections: §2.1 Syntax, §2.1.1 Formatting of Language Tags, §2.2.9 Classes of Conformance and §4.6 Considerations for Private Use Subtags.
- Retrieved: 2026-10-11.
- Complete source SHA-256: `5d9515f053163c80e7294a84d18217dc83471acc7caa9773da2ac40deeec8228`.
- Related matching specification: [RFC 4647](https://www.rfc-editor.org/rfc/rfc4647.txt), not a matching implementation claim.

The selected [HTML language clause](https://html.spec.whatwg.org/commit-snapshots/877d6146487f15b15bc8dd0e3c625063a37b456a/#language) remains the semantic authority. This boundary does not claim installed locale data, language recognition, registry-date-qualified tag validity or service support. An explicit validity operation needs its own selected grammar and registry basis; it must not silently replace captured raw values.

The original [RFC legal notice](../licenses/ietf-rfc5646/COPYRIGHT-NOTICE.txt) and [attribution/permission disposition](../licenses/ietf-rfc5646/NOTICE.md) are retained separately. Converted technical excerpts remain internal research because their redistribution basis is unresolved under the RFC's pre-November-2008 notice and the applicable historic legal provisions. This is a publication limit for source material, not a change to HTML's selected language behavior.
